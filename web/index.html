Flip Clock

一个简洁、优雅、开源的翻页时钟桌面应用。纯 CSS 翻页动画，多主题，本地优先，无遥测。

立即下载
当前版本 v1.0.22 macOSWindowsLinux MIT 开源

下载安装包

选择适合你操作系统的安装包，下载后即可运行

也可以使用 npm 安装：npm install -g flip-clock-app
若链接失效，请前往 GitHub Releases 手动下载。

功能特性

轻量 · 纯粹 · 专注显示时间本身

纯 CSS 翻页动画
无外部依赖，顺滑的 3D 翻转效果。
10 款主题
深色、浅色、米色、森林、日落、海洋等随心切换。
12 / 24 小时制
一键切换时间格式，支持显示秒。
农历显示
支持显示中文农历日期。
自定义座右铭
在时钟下展示你自己的每日寄语。
本地优先
无云、无遥测，一切数据只留在你的设备。
